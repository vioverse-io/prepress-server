      User Guide

      What This App Does

      A digital work order system for prepress. Create a job, fill in specs, write CSR instructions, and print or share. Everything saves to your browser automatically.

      Landing Page

      When you open the app, you see your recent work orders.

      • New Work Order (+) opens a form for job number, client, CSR, and components.
      • Recent grid — click any card to jump in.
      • Search bar — type a job number or client name to filter.

      The landing page also shows Archived jobs (restorable) and Templates (saved component presets). Filters at the top narrow by CSR, client, or date range.

      Creating a Job

      Click + in the nav bar or on the landing page. Fill in:

      • Job Number (required, must be unique)
      • Project Name (optional, e.g., "Spring Mailer")
      • Client Name (required, dropdown or type your own)
      • CSR Name (required, dropdown)
      • Components — select which pieces this job includes (Letter, Envelope, etc.). If you skip this, a default "Main" component is created.

      The Job Screen

      Header (billboard)

      Shows Job#, Customer, CSR, Component, and Version. Click any editable field to change it inline. The × button closes the job and returns to landing.

      Version has a picker (click the code) and a + button to auto-increment (A01, A02, A03...).

      Left Sidebar — CSR Instructions

      A rich text editor (bold, italic, underline, highlight, bullets, text size) for CSR notes.

      • Generate button reads your Piece Specs and inserts a formatted summary. If specs change after generating, printing will warn you it's stale.
      • Revisions: when you close a job, current instructions are timestamped and moved to revision history. The timeline at the bottom lets you click into any past entry.

      The sidebar is resizable. Drag the handle between the sidebar and checklist.

      Right Panel — Checklist

      Three collapsible sections of spec fields:

      • Piece Specs — Flat Size, Finished Size, Presswork, Press, Press Sheet, Print Marks, Number Up, Indicia, Head Info, Binding, Special Color, Previous Job#
      • File Path — Artwork, Mockup, SOF, Lives, Other
      • Variable Print — Address Block, 2D (camera), 2D (inserter), Match Job

      Each row has a toggle (on/off) and a text field. Turning a toggle off clears its text (except file paths). Many fields have dropdown presets — click the arrow or type your own.

      Required fields (Flat Size, Presswork, Press Sheet, Number Up, Press) show a red dot when empty. Envelopes skip Press Sheet and Number Up.

      Smart dropdowns: Flat Size and Press options automatically switch between standard and envelope choices based on the component name.

      Component Tabs

      Jobs can have up to 10 components (e.g., Letter + Envelope + Buckslip). Tabs appear above the checklist.

      • Click a tab to switch.
      • Double-click a tab name to rename.
      • Click + to add a new component (optionally from a template).
      • Click × on a tab to delete it (only when more than one).

      Each component has its own checklist, instructions, and version.

      Printing

      Two options in the print dropdown:

      • Print Current — prints the active component.
      • Print All Components — prints every component in sequence.

      Before printing, the app checks: required fields filled, specs physically valid (e.g., flat size vs. finished size), and specs summary up to date. You can override warnings.

      Templates

      Save a component's checklist as a reusable template: More > Save as Template. When adding a new component, select a template to pre-fill checkboxes and notes. Templates appear on the landing page.

      Duplicating

      • Duplicate Job — copies the entire job. Clears instructions, file paths, variable print, and previous job#. Opens Edit Job so you can update the number.
      • Duplicate Component — copies the current component within the same job. Same clearing rules.

      Import / Export

      • Export — pick which jobs to include, downloads a .json file.
      • Import — load a .json file. Preview shows what will be imported and flags duplicates.

      Data & Backup

      All data lives in your browser's localStorage. A secondary copy auto-saves to IndexedDB. If localStorage is ever cleared, the app auto-recovers from IndexedDB on next load.

      Restore from Backup (in the More menu) lets you manually pull from the IndexedDB backup.

      Profile

      Click the profile circle (top right) to set your nickname and upload a photo. Use the zoom slider and drag to crop your photo to fit the circle. Your name appears on timestamps and triggers personalized greetings on the landing page.

      Admin Password

      Destructive actions (delete job, delete template) require an admin password. This guards against accidental deletion.

      Limits

      • 20 active jobs max (archive old ones to make room)
      • 10 components per job
      • 15 undo steps
