      User Guide

      What This App Does

      Digital work orders for Prepress and Tech Services. Create a job, fill in specs, write instructions, print. Saves to SQL Server automatically.

      Landing Page

      A sortable, filterable table of all your jobs. Columns: Job#, Client, Project, CSR, Assigned, Signoff Due, Status, Depts.

      • New Work Order creates a job.
      • Click any row to open it.
      • My Jobs / All Jobs tabs -- "My Jobs" shows the jobs you created.
      • Search filters across job number, client, CSR, and project.

      Controls

      • Show row -- quick views: All, Overdue (red count), Due Today (amber count). Counts reflect all active jobs regardless of filters.
      • Group -- group rows by None, Status, or CSR.
      • Status -- filter by status: All, New, In Progress, On Hold, Complete, Cancelled.
      • Dept -- filter by department: All, Prepress, Tech Services.
      • CSR / Assignee / Client -- multi-select dropdowns. Active selections appear as chips below the controls.
      • Updated -- filter by last modified time: Today, This Week, This Month.

      Columns

      • Created -- the date and time the job was entered into the system. Click the header to sort by it, newest first. This is when the record was made, not the customer's in-hands date.
      • Assigned -- shows one department's assignee at a time. Click CS or TS in the header to switch.
      • Signoff Due -- shows the earlier of the two department due dates. Red "OVERDUE" tag for past-due jobs, amber "DUE SOON" within 12 hours. Complete and Cancelled jobs show muted text.
      • Status -- click the status badge on any row to change it (New, In Progress, On Hold, Complete, Cancelled).
      • Depts -- colored dots showing which departments have content.

      Bulk Actions

      Use the checkboxes on each row (or the select-all header checkbox) to select multiple jobs, then Archive or Delete them in bulk.

      Pagination

      The table shows 10 jobs per page. Use the page buttons below it, or the per page dropdown to switch to 25 or 50.

      Archived Jobs

      Archived jobs move out of the main table into the Archived panel below it. Nothing is deleted -- archiving just clears the job off the active list.

      • Search -- the box in the panel header filters the archive by job number, client, and project name. It searches archived jobs only; the job table above has its own separate search. The count badge shows "3 of 27" while a search is active.
      • Paging -- the panel shows 10 archived jobs at a time, newest first. Use Prev / Next at the bottom of the panel to move through pages.
      • Per page -- the dropdown in the panel header switches between 10, 25, 50, and 100 at a time. This dropdown controls the archive panel only; the job table has its own separate one.
      • Restore -- click the job name or the Restore button to move it back to the active list.
      • Delete -- the red x permanently deletes an archived job. This cannot be undone.
      • Archive on complete -- setting a job's status to Complete asks "Archive this job?" Choose Yes to archive it, No to leave it on the active list.

      Creating a Job

      Click New Work Order and fill in Job Number, Client, CSR, and which components the job has (Letter, Envelope, etc.). If you skip components, a default "Main" is created.

      The Job Screen

      Header

      Shows Job#, Customer, CSR, Component, Version, and Status. Click any field to edit it inline. Version has a picker and a + button to auto-increment (A01, A02, A03...). Click the status badge to change it (New, In Progress, On Hold, Complete, Cancelled).

      Department Tabs

      Two tabs above the checklist: Prepress and Tech Services. Click a tab to switch. Each department has its own checklist fields and its own instructions editor. They save independently.

      Left Sidebar -- Instructions

      Rich text editor for free-form instructions. Content is per-department: switching tabs switches the editor too.

      • Generate reads your checklist fields and writes a formatted summary. If fields change after generating, printing warns you it may be stale.
      • Revisions are saved when you close a job. Click any past entry in the timeline to view it.

      The sidebar is resizable. Drag the handle between the sidebar and checklist.

      Right Panel -- Prepress Checklist

      Three sections:

      • Piece Specs -- Flat Size, Finished Size, Presswork, Press, Press Sheet, Print Marks, Number Up, Indicia, Head Info, Binding, Special Color, Previous Job#
      • File Path -- Artwork, Mockup, SOF, Seeds & Samp, Lives, Record Counts, Other
      • Variable Print -- Address Block, 2D (camera), 2D (inserter), Match Job

      Each row has a toggle and a text field. Many fields have dropdown presets (click the arrow). Required fields show a red dot when empty. Flat Size and Press options switch automatically for envelope components.

      Right Panel -- Tech Services Checklist

      Five sections:

      • Data Conversion -- file locations, mailstreams, splitting, addressing fields
      • NCOA / CASS -- address standardization, move updates, movers handling, deceased suppression
      • Deduplication -- method (Individual / Household / Merge Households / Residential), file priorities, suppression match, rollup, casing
      • Presort -- data processing fields (pending finalization)
      • Print -- meeting required, variables, letter versions, signoffs, samples

      Same toggle + text pattern as Prepress. "Data file locations" is the only required field for now.

      Components

      Jobs can have up to 10 components (e.g., Letter + Envelope + Buckslip). Tabs appear above the checklist.

      • Click a tab to switch.
      • Double-click to rename.
      • + adds a new component (optionally from a template).
      • × deletes it (only when more than one).

      Each component has its own checklist, instructions, and version.

      Printing

      Three options in the print dropdown:

      • Print Current -- active component only.
      • Print All Components -- each component on a separate page.
      • Print All as One PDF -- all components combined into one document.

      Output uses the active department's color (red for Prepress, blue for Tech Services) and only shows that department's instructions and fields. The app warns if required fields are empty or the generated summary is out of date.

      Duplicating

      • Duplicate Job -- copies everything. Clears instructions, file paths, and variable print so you start fresh on those.
      • Duplicate Component -- copies within the same job. Same clearing rules.

      Import / Export

      • Export -- pick which jobs to export, downloads a .json file.
      • Import -- load a .json file. Shows a preview with new/updated/duplicate status for each job.

      Data & Backup

      Data lives on the SQL Server database. All users on the LAN share the same data. Local settings (theme, profile photo) are stored in your browser.

      Admin Password

      Deleting a job requires an admin password to prevent accidents.

      Multi-User

      This app runs on the company LAN. Multiple people can view and edit jobs at the same time. If someone else edits a job you have open, you'll see a "Job updated on the server" popup with a Reload job button. Use Refresh on the landing page to pull the latest data from the server.

      Limits

      • 10,000 active jobs
      • 10 components per job
      • 15 undo steps

      Manage CSRs & Assignees

      Names people can be picked from. Someone who leaves is turned off, not deleted, so their old jobs keep their name and still show up in the filters.

      These lists cannot be edited yet. The app is using its built-in names. Ask IT to check the server log for the one-line setup step.
      Old names on jobs (not on the list)

      These names are on existing jobs but are not on the list above -- usually different spellings of the same person from before. Move each one onto the correct name and every job that uses it updates at once.
